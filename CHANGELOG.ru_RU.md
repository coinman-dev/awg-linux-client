# История изменений

## 0.1.0-beta — 2026-11-22

Первая предварительная версия.

### Добавлено

- Графический клиент AmneziaWG / WireGuard для Linux в одном исполняемом файле (Rust, egui)
  по образцу amneziawg-windows-client: список туннелей с состоянием, подключение и
  отключение, подробности интерфейса и пиров с живой статистикой (последнее рукопожатие,
  трафик, адрес сервера, параметры обфускации AmneziaWG).
- Импорт `.conf`-файлов (диалог, перетаскивание, `--import`), вставленного текста конфига и
  ключей AmneziaVPN `vpn://`; новый пустой туннель со сгенерированной парой ключей; редактор
  с подсветкой синтаксиса; экспорт и удаление.
- Встроенный бэкенд: `amneziawg-go`, `awg` и `awg-quick` встроены и распаковываются в
  `/var/lib/awg-gui/bin`, если в системе нет своих, поэтому не нужны ни модуль ядра, ни
  пакеты AmneziaWG.
- Привилегированный helper запускается через `pkexec` один раз за сеанс; пакет ставит
  polkit-политику с понятным сообщением и запоминанием авторизации.
- Иконка в системном трее (StatusNotifierItem) с переключением туннелей; закрытие окна
  сворачивает программу в трей; автозапуск при входе в систему сразу в трей; один экземпляр.
- Светлая, тёмная и системная темы; русский и английский интерфейс; журнал операций.
- Deb-пакет `awg-gui_<версия>_amd64.deb` с ярлыком, иконками и polkit-политикой; release
  workflow на GitHub Actions.
